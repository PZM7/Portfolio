FakeStoreDashboard

Dashboard responsive para explorar un catálogo remoto con búsqueda, filtros, ordenación y detalle de producto.

Problema
Presentar y explorar los datos de Fake Store API con estados de carga, error y vacío comprensibles.
Decisión técnica
Estado local para un alcance pequeño, peticiones paralelas y transformaciones en memoria con useMemo.
Resultado
Flujo completo de catálogo y detalle, adaptado a móvil, tablet y escritorio.
